# Event-Driven Trading and Financial Analysis

This repository contains a collection of Python tools and scripts for event-driven trading, financial data storage, forecasting, and time series analysis. It is designed to provide a modular framework for backtesting trading strategies and performing quantitative financial analysis.

## Repository Structure

The project is organized into several modules, each focusing on a specific aspect of quantitative trading:

- **`event_driven_trading/`**: Core framework for event-driven backtesting, including data handling, strategy implementation, portfolio management, and execution handling.
- **`financial_data_storage/`**: Scripts for managing financial data in a MySQL database, including symbol insertion and price retrieval from AlphaVantage.
- **`forecasting/`**: Tools for financial time series forecasting using machine learning models like Random Forests and SVMs.
- **`performance_measurement/`**: Utilities for calculating performance metrics such as the Sharpe Ratio.
- **`pricing/`**: API wrappers for financial data providers (e.g., AlphaVantage).
- **`processing_financial_data/`**: Scripts for processing financial data, such as handling continuous futures contracts and IQFeed data.
- **`risk_n_money_management/`**: Tools for risk management, including Value-at-Risk (VaR) calculations.
- **`strategy_optimisation/`**: Utilities for optimizing trading strategies using techniques like grid search and cross-validation.
- **`time_series_analysis/`**: Statistical tools for time series analysis, including Augmented Dickey-Fuller (ADF) and Cointegrated Augmented Dickey-Fuller (CADF) tests.
- **`trading_strategy_implementation/`**: Examples of specific trading strategy implementations (e.g., Moving Average Crossover).

## Getting Started

### Prerequisites

- Python 3.x (Note: Some scripts may require adjustments for Python 2/3 compatibility)
- MySQL (for data storage modules)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/event-driven-trading.git
   cd event-driven-trading
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Usage Examples

#### Running a Backtest

To run a Moving Average Crossover backtest:

```bash
cd trading_strategy_implementation
python mac.py
```
*(Note: You will need to update the `csv_dir` path in `mac.py` to point to your local data.)*

#### Performing an ADF Test

```bash
cd time_series_analysis
python adf.py
```

## Key Components

### Event-Driven Architecture

The backtesting engine uses an event-driven approach, where components communicate via an event queue:

- **`MarketEvent`**: Triggered when new market data is available.
- **`SignalEvent`**: Generated by a `Strategy` when a trading signal is identified.
- **`OrderEvent`**: Created by the `Portfolio` based on signals.
- **`FillEvent`**: Produced by the `ExecutionHandler` when an order is "filled".
